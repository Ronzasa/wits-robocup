# Original Architect independent evaluation

This branch investigates the prior deadline evidence, fixes the Adaptive report
and evaluates the **unchanged Original Architect** independently against frozen
TITAN v10.0. No challenger is promoted automatically.

- [Deadline investigation and reporting correction](deadline-and-reporting-audit.md)
- [Preregistered rules and seed audit](registration.json)
- [Fresh development protocol](development-protocol.json)
- [Reserved fresh 768-pair qualification protocol](qualification-protocol.json)
- [Development report](development-results.md)
- [Final stage decision](decision.json)
- [Evidence index](evidence.json)

The eight development opponents are frozen v10, pressing, compact,
counterattacking and long variants, v9.1, tight-links and wide-switch styles.
Twelve fresh seed blocks, both sides and both kickoffs give 384 matched pairs
and 768 original native full matches. Qualification is separately reserved:
sixteen untouched blocks across twelve styles give exactly 768 pairs.

Development retains the previous conservative Original Architect criteria:
more raw and accepted points, positive 97.5% whole-seed lower bounds, exact
one-sided p≤.025, no per-style raw points regression, more completed passes,
no extra turnovers, at least five support episodes, and all original SDK,
action-legality, exception and native runtime gates. No criterion is relaxed
because the candidate looked promising in an earlier cohort.

The sources, source flags, physics, SDK, configuration and 20 ms deadline stay
unchanged. Counterattack Firewall, Adaptive and the four older special tactics
remain disabled. Sources and fresh cohorts are sealed before native play.
No outcome tuning, cohort extension or opponent removal is allowed.

Every original match and every exact repeat uses the same tracing. SDK wall
time, thread CPU, GC overlap, public-observation fingerprints and both teams'
slow calls are retained. Fixture-level recurrence, same-public-input recurrence
and a new miss first appearing on repeat are distinct observations; any first
repeat candidate miss still fails the conservative gate. No old or new miss
is silently discarded or excused as environmental noise.

The historical Adaptive archive is immutable. Its embedded old report is
superseded by the corrected live report and a documented erratum; the tables,
statistics, gates and policy sources never changed. The regeneration regression
checks actual archived data, not a hand-built replica of the formatter.

Only a full development pass starts the registered qualification. Even a full
qualification pass authorizes only an evidence-backed recommendation. Main and
the active champion still require explicit user approval before any change.
